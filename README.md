# Kaos-screensaver

This is a companion screensaver to the Kaos app which I'm working on.

If you remember the old Kaos fractal app for the Mac by Reinoud Lamberts, this is the same engine with a modern build.

To install - simply unzip the archive and double-click the .saver file.
